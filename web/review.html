Canonical course matches

Each canonical course and every school's rows matched to it.

What this shows. Courses are compared across schools through a shared list of canonical courses. Each canonical course has a description written for this project, not copied from any school. A new match means that row created the canonical course. High / medium / low is the confidence that a row belongs to an existing one. A row may match several canonical courses and is listed under each. Possible marks a real choice (the student takes one of the options), and all options taken, in either order marks options the plan lists only so students can pick the order. To approve or reject a match, edit match_status in data/reference/<school>/matches.csv, then rerun src/build_outputs.py --school <school>.
Generic descriptions are marked generic. They are typical descriptions of a course or requirement with that name, written for this project, not the school's own catalog text.
