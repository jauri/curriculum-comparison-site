Concept vocabulary

The draft concepts in data/reference/concepts.csv, by group, for review before tagging.

What this shows. Each concept's name, definition (written for this project), and synonyms (phrases that occur word for word in the in-scope descriptions). The dots are the 16 schools: UC first (larger, orange), then the comparison schools in a fixed order (hover a dot for the school and its matching courses): filled means the school has at least one in-scope course whose title or description contains a synonym. Within each group, concepts are sorted by how many schools mention them (most first). Appears in lists the canonical courses those courses match, with the number of schools for each. These are rough phrase matches, not tags: a synonym can occur in another sense ("functions" in a discrete-math course), and a concept can be stated in other words. Tags are proposed by reading each description in step 17. In scope: CS courses with the school's own catalog text (no generic descriptions, no slots).
Truncated catalog text. Some descriptions are cut off in the school's own catalog (e.g. UC's CS 2028C Data Structures ends at "Vectors, Lists, Stacks, Queues, Sets,"). Such rows are marked below, and concepts they would mention don't show up for them. To change a concept, edit concepts.csv and rerun src/preview_concepts.py.
